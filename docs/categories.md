## 세무 성격이 뜻하는 것

| 표기 | 의미 |
|---|---|
| 업무용 가능 | G2 를 통과할 수 있다. 다만 사용자 진술이 필요할 수 있다 |
| 혼재 | 사업/개인이 섞인다. 안분 또는 되묻기 대상 |
| 사업 무관 후보 | 개인 소비로 볼 가능성이 높다 |
| 불산입 후보 | G1 에서 걸러질 후보. **판정은 룰카드가 한다** |
| 되묻기 필요 | 카테고리만으로는 판정 불가 |

**카테고리는 `verdict` 가 아닙니다.** 사전·키워드룰은 category 만 정하고,
경비 가능 여부는 6관문 룰카드가 판정합니다. 위 '세무 성격' 은 룰카드를
설계할 때의 분류 의도를 적어둔 것이고, 그 자체가 판정이 아닙니다.
