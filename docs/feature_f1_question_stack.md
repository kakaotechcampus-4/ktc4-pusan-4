# F1 · 되묻기 카드 스택

> **부분 이관 문서다.** F1 의 원본은 노션 기능 명세서이고, 여기는 PR #21
> 답글에서 약속한 두 가지 동작(미해소 건 상시 표시 / 남은 소액 꼬리 일괄 처리)을
> 명세에 반영하려고 해당 부분만 옮긴 것이다. 나머지 F1 항목(카드 UI, 애니메이션,
> 진행률 표시 등)은 노션을 봐야 한다.

관련: [`api_questions.md`](api_questions.md) · PR #21 · PR #11(연간 확정 조건)

---

## 동작 요약

규칙으로 판정이 확정되지 않은 거래를 카드 스택으로 하나씩 묻는다.
질문은 `group_by`(기본 `merchant_norm`)로 묶여서, 같은 가맹점 12건이
카드 한 장이 된다.

---

## F1-a. 배치로 보여준다 (질문을 자르지 않는다)

- 한 번에 `batch_size`(잠정 15)개만 보여준다. 다 답하면 다음 배치가 나온다.
- **첫 화면에서 200문항을 보여주지 않는 것이 목적이다.** 질문을 없애는 게 아니다.
- 절단하면 두 가지가 깨진다.
  - PR #11 의 연간 확정 조건이 "미응답 질문 없음" 이라 확정이 영원히 안 된다.
  - 미분류 건이 요건 충족 합계에서 빠져 사용자가 경비를 덜 계상한다.

## F1-b. 미해소 건은 상시 표시한다

배치 밖으로 밀린 질문도 **항상 눈에 보여야 한다.**

- 화면에 상시 노출: **"확인 필요 24건 · 340,000원"**
  (`total_unresolved`, `unresolved_amount`)
- 집계에서는 **요건 충족 합계에 들어가지 않는다.** 별도로 **"미확정"** 금액으로
  표시한다. 확정된 경비와 섞으면 사용자가 실제보다 많이 계상한 것으로 오해한다.
- 5월 확정 전에는 전부 해소해야 한다. 확정 조건이 강제한다 — UI 가 따로
  막지 않아도 확정 버튼이 열리지 않는다.

## F1-c. 남은 소액 꼬리는 일괄 처리한다

마지막까지 남는 꼬리를 한 건씩 묻지 않는다.

- **"남은 12건 전부 개인용"** 같은 일괄 답변을 제공한다.
  (`POST /api/questions/bulk-answer`)
- 일괄 처리 후에도 **개별 건을 다시 바꿀 수 있어야 한다.** 되돌릴 수 없으면
  사용자가 누르기를 주저한다.
- 일괄 처리로 전부 닫히지 않을 수 있다. 다른 `fact_type` 을 묻는 질문은
  건너뛰어지고, 남은 수는 응답의 `total_unresolved` 로 그대로 보여준다.

---

## 미정 — 결정 필요

- **일괄 처리를 어느 시점에 노출할지.** 항상 보이면 사용자가 첫 배치부터
  전부 개인용으로 닫아버릴 수 있다. 남은 건이 일정 수 이하이거나 금액이
  작을 때만 노출하는 안을 제안한다.
- **"소액" 의 기준.** 위 노출 조건을 금액으로 걸 경우 필요하다.
- `batch_size` 기본값 15 는 잠정값이다. 근거와 재측정 조건은
  [`api_questions.md`](api_questions.md) 참고.
