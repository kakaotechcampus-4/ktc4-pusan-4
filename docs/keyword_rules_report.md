# T3 키워드 분류 규칙 리포트

`rules/keyword_rules.yaml` 을 실제 카드 내역에 적용한 결과다.
적용 순서는 **PG 블록 -> 시드 사전 -> 키워드룰 -> uncertain** 이고,
시드 사전(T4)이 아직 없어서 이 리포트는 **PG + 키워드룰만** 적용한 수치다.
사전이 생기면 커버리지는 올라간다.

상호명 익명화는 T1 규칙을 따른다. PG 상호는 익명화하지 않는다(T2 판단 유지).

생성: `python tools/keyword_rules.py --report`

## 1. 커버리지

| 단계 | 건수 | 비율 |
|---|---:|---:|
| PG 블록 (되묻기) | 19 | 5.6% |
| 키워드룰 분류 | 242 | 71.6% |
| uncertain (되묻기) | 77 | 22.8% |
| **합계** | **338** | |

**PG 제외 후 커버리지 75.9%** (242/319). PG 로 빠진 19건은 애초에 되묻기 대상이라 분모에서 뺐다.

### 되묻기 물량 추정

| | 건수 |
|---|---:|
| PG 블록 | 19 |
| uncertain | 77 |
| **되묻기 합계** | **96** (전체의 28.4%) |

되묻기는 **상호 단위로 묶인다**. uncertain 유니크 상호는 45개라서, 사용자가 실제로 답해야 하는 질문은 77건이 아니라 45개에 가깝다.

| `배민클럽_우아한형제들-배민클럽_우아한형제들` | `배민클럽` (구독서비스) | `배달의민족\|우아한형제들\|요기요` (음식배달, p=740) |

## 5. 과잉 매칭 감시

짧거나 흔한 패턴이 실제로 무엇을 잡았는지 매번 확인한다.

| 패턴 | 잡은 상호 수 | 잡은 것 (분류 결과) |
|---|---:|---|
| `KT\b` | 0 | — |
| `CU\b` | 3 | `씨유***` (편의점), `씨유*** (2)` (편의점), `씨유*** (3)` (편의점) |
| `커피` | 7 | `카페 A` (카페), `카페 B` (카페), `카페 C` (카페), `카페 D` (카페), `컴포즈***` (카페), `카페 E` (카페) … |
| `스팀\|STEAM` | 1 | `Steam (Korea)` (게임) |
| `다이소` | 2 | `아성다이소` (사무용품), `주식회사 아성다이소` (사무용품) |
| `쿠팡` | 0 | — |
| `GCP` | 0 | — |
| `빵` | 0 | — |

현재 데이터에서 오탐은 확인되지 않았다. 다만 아래는 표본이 커지면 터질 수 있다.

- `KT\b` : `KT&G` 같은 상호를 잡는다. 담배 구매가 통신비로 분류된다
- `CU\b` : 영문 상호 중 CU 로 끝나는 것이 있으면 편의점이 된다
- `커피` : 상호에 커피가 들어간 음식점(디저트 카페 등)이 카페로 간다. 실무상 차이는 작다
- `스팀|STEAM` : `스팀청소`, `스팀세차` 가 게임으로 분류된다

## 7. PM 판단 필요

### 게임 / 구독서비스

- 질문: T0 에서 고정한 category enum 22종에 없는 값이다. enum 에 추가할지, 기타로 흡수할지
- 현재 처리: enum 에 추가하고 validate_rules.py 를 통과시켰다. [PM 확인] 표시함

### 학교·국군복지단 매점

- 질문: 상호는 학교인데 업종은 매점이다. 교육으로 볼지 편의점으로 볼지
- 현재 처리: 교육으로 분류. 실증 2건

### 다이소

- 질문: 사무용품인지 기타인지. 생활용품이 섞인다
- 현재 처리: 사무용품으로 분류

### 노래연습장 / 헤어살롱 / PC방

- 질문: enum 에 여가·미용 카테고리가 없다. 기타로 두면 되묻기로 간다
- 현재 처리: 룰을 만들지 않았다. uncertain 으로 남겨 되묻기로 보낸다
