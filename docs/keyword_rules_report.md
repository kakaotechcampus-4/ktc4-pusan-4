# T3 키워드 분류 규칙 리포트

`rules/keyword_rules.yaml` 을 실제 카드 내역에 적용한 결과다.
적용 순서는 **PG 블록 -> 시드 사전 -> 키워드룰 -> uncertain** 이고,
시드 사전(T4)이 아직 없어서 이 리포트는 **PG + 키워드룰만** 적용한 수치다.
사전이 생기면 커버리지는 올라간다.

상호명 익명화는 T1 규칙을 따른다. PG 상호는 익명화하지 않는다(T2 판단 유지).

생성: `python tools/keyword_rules.py --report`

|---|---|---|
| `배민클럽_우아한형제들-배민클럽_우아한형제들` | `배민클럽` (구독서비스) | `배달의민족\|우아한형제들\|요기요` (음식배달, p=740) |

## 5. 과잉 매칭 감시

짧거나 흔한 패턴이 실제로 무엇을 잡았는지 매번 확인한다.

| 패턴 | 잡은 상호 수 | 잡은 것 (분류 결과) |
|---|---:|---|
| `KT\b` | 0 | — |

| `커피` | 7 | `카페 A` (카페), `카페 B` (카페), `카페 C` (카페), `카페 D` (카페), `컴포즈***` (카페), `카페 E` (카페) … |

| `다이소` | 2 | `아성다이소` (생활용품), `주식회사 아성다이소` (생활용품) |

현재 데이터에서 오탐은 확인되지 않았다. 다만 아래는 표본이 커지면 터질 수 있다.

- `KT\b` : `KT&G` 같은 상호를 잡는다. 담배 구매가 통신비로 분류된다
- `CU\b` : 영문 상호 중 CU 로 끝나는 것이 있으면 편의점이 된다
- `커피` : 상호에 커피가 들어간 음식점(디저트 카페 등)이 카페로 간다. 실무상 차이는 작다
- `스팀|STEAM` : `스팀청소`, `스팀세차` 가 게임으로 분류된다

## 7. 도메인 패턴 — 확정 분류에서 힌트로

`.COM$ .APP$ .IO$ .DEV$ .AI$` 를 해외SaaS 로 확정하던 것을 되묻기 힌트로 바꿨다.
국내 사이트도 `.com` 으로 끝나고, 도메인만으로 해외 판정은 근거가 약하다.
패턴 자체는 `RESEND.COM`, `RAILWAY.APP` 같은 신규 SaaS 롱테일을 놓치지 않기 위해 남겼다.

| | 건수 |
|---|---:|
| 이 패턴에 걸려 uncertain 으로 간 건 | 0 |
| 그중 유니크 상호 | 0 |

**커버리지 영향 없음.** 현재 데이터에는 이 패턴에 걸리는 상호가 없다.
(해외 결제 문자열이 `ANTHROPIC* CLA` 처럼 도메인 형태가 아니라 잘려서 온다)

되묻기 화면에서는 `hint` 를 그대로 띄워 질문을 좁힌다 — 
"해외 서비스 결제로 보입니다. 업무용이 맞나요?" 처럼 물을 수 있다.

## 8. 새 카테고리가 회수한 건

## 9. PM 판단 필요

### 헬스장 / 피트니스

- 질문: 여가에 넣었다. 노래방·PC방과 세무 판정이 같다고 봤는데 맞는가
- 현재 처리: 여가로 분류. 실증 1건

### 과잉 매칭 감시 (KT, 스팀, CU, 노래)

- 질문: 현재 오탐 0건. 표본이 늘면 재확인한다
- 현재 처리: 리포트 5장에 경고를 유지한다 (PM 지시)
