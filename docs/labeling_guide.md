# 참고 자료

## 이슈 #22 — 사업자번호 트랙 분기

- 같은 가맹점인데 어떤 행에는 사업자번호가 있고 어떤 행에는 없어서, 하나는
  사업자번호 트랙(숫자 키), 하나는 문자열 트랙(상호명 키)으로 갈린다.
- 사업자번호 커버리지가 31.3% 라 구조적으로 흔하다. IBK 는 주고 KB 는 안 주며,
  의료 마스킹 행은 역추적 방지로 일부러 지운다.
- 상호 단위 되묻기의 전제가 깨진다 — 같은 가맹점에 두 번 질문하게 된다.
  해결 방향은 별칭 테이블이 유력하고, 이슈 #35 의 브랜드 사전과 역할이 겹친다.

## 이슈 #35 — 한글 브랜드 경계

- 경계 문자(영문·숫자·공백)가 없으면 `[가-힣]{2,}점$` 이 브랜드명까지 먹고,
  `min_keep` 가드가 막는다. 막은 뒤엔 지점명이 그대로 남아 점포마다 키가 갈린다.
- 카드 전표는 브랜드와 지점 사이에 공백을 넣는 경우가 있어 분리되지만, 사업자
  등록 상호는 공백이 없다. 상권정보 1,492건에서 세븐일레븐 390건이 전부 갈렸다.
- 정규식으로는 못 푼다. 브랜드 사전 prefix 매칭이 필요하고, 그게 T4 시드 사전의
  1층이다. **이 기준표의 1층이 그 사전의 입력이다.**
