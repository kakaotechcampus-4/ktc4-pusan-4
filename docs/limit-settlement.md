# 연간 한도 집계 결정사항

G6는 건별 판정 중에 한도 버킷과 대상 금액만 태그한다. 인정 금액은 같은 사용자,
귀속연도, 버킷의 전체 거래를 모은 뒤 별도 집계 단계에서 계산한다.

## 배분 순서

1. 승인일 오름차순
2. 승인일이 같으면 판정 UUID 오름차순

입력 목록의 순서와 무관하게 같은 결과가 나오도록 위 순서를 항상 적용한다.

## 상태 전이

- 재계산 결과는 항상 `잠정`으로 저장한다.
- 당해연도 수입금액이 확인되고, 미응답 질문과 검토 대기 판정이 모두 없을 때만
  `확정`으로 전환한다.
- 답변이나 정정으로 다시 계산하면 기존 확정 결과도 `잠정`으로 되돌린다.
- 재계산 대상에서 빠진 항목은 해당 버킷에서 제거한다.
