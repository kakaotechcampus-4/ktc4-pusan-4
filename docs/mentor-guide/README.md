# 멘토 테스트 가이드

멘토님이 PreeT 를 처음부터 끝까지 직접 써 보며 흐름을 확인하실 수 있게 만든 가이드입니다. (#277)

- `index.html` — 가이드 본문. 브라우저로 열면 됩니다. GitHub 화면에서는 코드로 보이니 폴더를 내려받아 여세요.
- `img/` — 단계별 실서버 캡처. 빨간 점선 번호가 본문 설명 번호와 짝입니다.

업로드는 화면의 「샘플 파일로 해 보기 → 무작위 카드내역 만들기」(#285)를 씁니다. 누를 때마다 새 카드내역이 만들어집니다.
캡처는 2026-11-10 배포(#287) 기준입니다. 분류 확인 · 질문 예시 일부는 「KB국민카드 승인내역」 샘플로 찍었습니다. 화면이 바뀌면 캡처도 다시 찍어야 합니다.
