# 멘토용 테스트 가이드

PreeT는 1인 프리랜서(업종코드 940909)의 카드 승인내역을 올리면, 거래마다 경비로 넣을 수 있는지 판정하고 근거 조문을 보여주는 서비스입니다.

- 주소: https://ktc4-pusan-4.duckdns.org
- 테스트 계정: 따로 전달드립니다
- 소요 시간: 10~15분

## 1. 진행 순서

1. 카드내역 업로드
2. 분류 확인
3. 사업자 문진
4. 판정 전 확인
5. 결과 확인
6. 질문에 답하기 (답하면 바로 다시 판정됩니다)
7. 요약 · CSV 내려받기

## 2. 문진 입력 예시

로그인하면 사업자 문진 화면이 먼저 나옵니다. 아래처럼 넣어 주세요.

| 항목 | 입력값 | 영향 |
| --- | --- | --- |
| 업종 | 프리랜서, 인적용역 | 현재 이 업종만 선택할 수 있습니다 |
| 직전연도 수입금액 | 50,000,000 | 접대비 한도, 기장의무 자동 선택 |
| 개업일 | 과거 날짜 아무거나 | 없음 |
| 기장의무 | 자동 선택 (간편장부) | 없음 |
| 직원 | 없음 | 없음 |
| 자택 작업 | 예, 20% | 자택 겸용 거래의 경비 금액 |

참고할 점

- 수입금액은 소득이 아니라 매출(받은 돈 합계)입니다.
- 수입금액은 가능·불가 판정에는 영향이 없고, 접대비 한도 금액만 바꿉니다.
  - 한도 = 1,200만 원 + 수입금액 × 0.3%
  - 5,000만 원이면 1,215만 원
  - 940909는 중소기업 특례(3,600만 원)를 적용하지 않습니다. (사전-2025-법규소득-0245)
- 귀속연도는 따로 묻지 않고 승인일 기준으로 정합니다.
- 문진은 나중에 판정 전 확인 화면이나 내 정보에서 고칠 수 있습니다.

## 3. 확인해 주셨으면 하는 것

1. 질문에 답하면 판정이 바로 바뀌는지
   - 예: 구독 서비스를 "업무 전용"으로 답하면 가능으로 바뀝니다.
2. 자택 비율이 금액에 반영되는지
   - 전기요금이나 월세를 "자택 겸용"으로 답하면 경비 금액이 결제액의 20%로 나옵니다.
3. 100만 원이 넘는 물건
   - "자산으로 등재"를 고르면 올해 경비가 결제액보다 적게(감가상각) 나옵니다.
4. 요약 화면
   - 경비 가능 금액, 접대비 한도, 세무사 전달용 문장, CSV 내려받기
5. 판정 직접 수정
   - 결과 상세에서 판정을 바꾸면 "직접 수정" 표시와 이력이 남습니다.

## 4. 판정 확인 방법

결과 화면에서 거래를 누르면 오른쪽에 상세가 열립니다.

- 업종: 가맹점 이름 아래. 가맹점 성격과 맞는지 봐 주세요. (예: 교보문고 → 도서)
- 판정 이유: 불가·확인 필요일 때 이유가 나옵니다.
- 근거 조문: 맨 아래. 국가법령정보 링크로 원문을 볼 수 있습니다.
- 경비 가능 금액: 자택 비율, 감가상각, 한도가 반영된 금액입니다.

판정은 세 가지입니다.

| 판정 | 뜻 | 예 |
| --- | --- | --- |
| 가능 | 업무 관련 지출 (소득세법 §27①) | 도서, 소프트웨어, 업무 미팅 식대 |
| 불가 | 법상 제외(§33①)되거나 개인 지출로 보는 경우 | 세금·과태료, 의료비, 주말 식대 |
| 확인 필요 | 사실 확인이 필요해 질문으로 넘어감 | 평일 식대, 통신비, 전자기기 |

## 5. 알려진 한계

- 가능 판정에는 이유 문장 없이 근거 조문만 나옵니다. (#132)
- 어떤 규칙 카드로 판정됐는지는 화면에 나오지 않습니다. 개발자도구에서 `/judgments` 응답의 `ruleCardId`로 볼 수 있습니다.
- 자동 분류된 업종은 화면에서 바꿀 수 없습니다. 분류가 틀리면 판정을 직접 수정해야 합니다.
