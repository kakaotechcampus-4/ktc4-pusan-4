# 멘토용 테스트 가이드

PreeT 를 처음 써 보시는 분이 **무엇을 넣고, 무엇을 확인하면 되는지** 한 장으로 정리했습니다.
테스트 계정은 따로 전달드립니다. 10~15분이면 끝까지 둘러보실 수 있습니다.

- 서비스: https://ktc4-pusan-4.duckdns.org
- 대상 사용자: 1인 프리랜서(인적용역, 업종코드 940909)
- 하는 일: 카드 승인내역 → 업종 분류 → 규칙 엔진 판정(가능 · 불가 · 확인 필요) + 소득세법 조문 근거

---

## 1. 흐름 한눈에 보기

```
/upload 카드내역 → /preview 분류 확인 → /interview 사업자 문진 → /confirm 판정 전 확인
→ /results 결과 → /questions 질문에 답하기(답하면 바로 다시 판정) → /summary 요약 · CSV
```

## 2. 입력 예시 — 사업자 문진

가입 직후 「사업자 문진」 화면이 열립니다. 아래 값을 그대로 넣으시면 됩니다.

| 항목 | 넣을 값 | 이 값이 바꾸는 것 |
| --- | --- | --- |
| 1. 업종 | **프리랜서, 인적용역** (지금은 이것만 고를 수 있습니다) | 규칙 카드 대부분이 이 업종에 맞춰져 있습니다 |
| 2. 직전연도 수입금액 | **50,000,000** | 기업업무추진비(접대비) 연 한도, 기장의무 자동 선택 |
| 3. 개업일 | 아무 과거 날짜 (예: 2024-03-01) | 현재 판정에는 영향 없음 |
| 4. 기장의무 | 수입금액에 따라 자동 선택 (5,000만 원 → 간편장부) | 현재 판정에는 영향 없음 |
| 5. 직원이 있나요? | 없음 (1인) | 현재 판정에는 영향 없음 |
| 6. 자택에서 작업하나요? | **예, 20%** | 전기 · 임차료를 「자택 겸용」으로 답했을 때 경비 금액 = 결제액 × 20% |

**자주 헷갈리는 점**
- 「직전연도 수입금액」은 **소득(수입 − 경비)이 아니라 매출(받은 돈 합계)** 입니다. 「전년도 소득액」 칸은 따로 없습니다.
- 수입금액은 **가능 · 불가 판정을 바꾸지 않습니다.** 접대비 한도 금액만 바뀝니다.
  - 한도 = 1,200만 원 + 수입금액 × 0.3% (수입 100억 원 이하일 때)
  - 50,000,000 → 12,000,000 + 150,000 = **12,150,000원**
  - 940909 면세 인적용역사업자는 중소기업 특례(3,600만 원)를 적용하지 않습니다 (사전-2025-법규소득-0245)
- 귀속연도 칸은 없습니다. 승인일의 연도로 정합니다.
- 문진은 「판정 전 확인」 화면의 「문진 고치기」나 「내 정보」에서 다시 고칠 수 있습니다.

## 3. 테스트용 카드셋

카드사 파일이 없으셔도 됩니다. 업로드 화면 아래 **「샘플 파일로 해 보기」** 에서 **KB국민카드 승인내역** 또는 **IBK기업은행 승인내역** 버튼을 누르면 바로 올라갑니다. 두 개 다 올려 보셔도 됩니다.

샘플에 들어 있는 거래와 **예상 결과**입니다. 결과 화면이 아래와 다르면 알려 주세요.

| 거래 (샘플) | 분류되는 업종 | 예상 판정 | 확인 포인트 |
| --- | --- | --- | --- |
| 스타벅스 서면점 11,000 (1/3 토요일) | 카페 | 불가 · 답변 대기 | 주말 카페는 개인 지출로 보고 빼고, 「거래처 미팅이었나요?」를 묻습니다 |
| 서면연세의원 15,000 · 부산약국 4,500 | 의료 | 불가 | 의료비는 가사 관련 경비 (소득세법 §33①5) |
| 교보문고 22,000 | 도서 | 가능 | 업무 관련 도서 (§27①) |
| 넷플릭스 13,500 | 구독서비스 | 확인 필요 | 「이 구독은 업무 전용인가요?」 질문 |
| 지하철 모바일 50건 62,500 | 여비교통 (합산 행) | 확인 필요 | 합산 행이라 주말 규칙을 적용하지 않고 용도를 묻습니다 |
| GS25 3,000 | 편의점 | 확인 필요 | 용도 질문 |
| 하이마트 360,000 (3개월 할부) | 전자기기 | 확인 필요 | 「이 기기는 업무용인가요?」, 100만 원 이하라 즉시상각 |
| 하이마트 1,200,000 (IBK) | 전자기기 | 확인 필요 | 업무용 질문 + 100만 원 초과라 「올해 경비 / 자산 등재」 질문 |
| 쿠팡이츠 21,000 (3/1 삼일절) | 음식배달 | 불가 · 답변 대기 | 공휴일 배달은 개인 지출로 보고 소명을 받습니다 |
| 구글플레이 4,400 | PG(결제대행) 미상 | 확인 필요 | 무엇을 샀는지 몰라 용도를 묻습니다 |
| 쿠팡 39,000 + 같은 금액 취소 | – | 판정 대상 아님 | 결제와 취소가 서로 지워집니다 |
| 0원 · 포인트 사용 행 | – | 판정 대상 아님 | 판정에서 자동으로 빠집니다 |

> 위 「예상 판정」은 규칙 카드와 키워드 사전으로 정리한 값입니다. 같은 계정에서 분류를 직접 고른 적이 있으면 그 선택이 먼저 적용되어 달라질 수 있습니다.

## 4. 체크해야 할 포인트

1. **질문에 답하면 판정이 바로 바뀌는가**
   - 「답할 질문」에서 넷플릭스를 「업무 전용」으로 답하면 → 가능
   - 스타벅스를 「업무미팅」으로 답하면 → 가능(기업업무추진비, 연 한도 대상)
2. **자택 비율이 금액에 반영되는가** — 전기요금 · 월세 같은 거래가 있으면 「자택 겸용(작업 공간이 따로 나뉨)」으로 답해 경비 금액이 결제액 × 20% 인지 봅니다
3. **100만 원 넘는 물건** — 하이마트 1,200,000원에서 「자산으로 등재」를 고르면 올해 넣을 금액이 결제액보다 작게(감가상각) 나오는지 봅니다
4. **요약 화면** — 경비 가능 금액, 접대비 한도(문진 수입금액 기준 잠정), 세무사에게 넘길 문장, CSV 내려받기
5. **판정을 직접 바꾸기** — 결과 상세에서 「가능으로/불가로 바꾸기」를 누르면 「직접 수정」 표시와 이력이 남는지

## 5. 분류 · 판정이 맞는지 확인하는 기준

결과 화면에서 거래를 누르면 오른쪽에 상세가 열립니다. 아래 순서로 보시면 됩니다.

| 무엇을 볼지 | 어디에 있는지 | 맞게 된 경우 |
| --- | --- | --- |
| 업종(카테고리) | 상세 맨 위, 가맹점 이름 아래 | 가맹점 성격과 맞음 (예: 교보문고 → 도서) |
| 판정 이유 | 「판정 이유」 칸 | 불가 · 확인 필요일 때 이유 문장이 있음 |
| 근거 조문 | 상세 맨 아래 「근거 조문」 | 조문 제목 + 「국가법령정보」 링크로 원문 확인 가능 |
| 금액 | 「경비 가능 금액」 | 자택 비율 · 감가상각 · 한도가 반영됨 |

**판정 기준 요약**

| 판정 | 뜻 | 대표 예 |
| --- | --- | --- |
| 가능 | 업무 관련 지출로 필요경비 인정 (§27①) | 도서, 국내 SW, 업무 전용 구독, 업무미팅 식대 |
| 불가 | 법이 막거나(§33①) 개인 지출로 보는 경우 | 세금 · 과태료, 의료 · 미용 · 게임, 주말 · 공휴일 식대(소명 전) |
| 확인 필요 | 사실을 알아야 판단 가능 → 질문으로 이어짐 | 평일 식대, 통신비, 온라인쇼핑, 전자기기 |

**지금 화면의 한계** (테스트 중 헷갈리실 수 있는 부분)
- 「가능」 판정에는 이유 문장이 없고 **근거 조문만** 보입니다. 서버의 판정 설명(explanation)이 아직 비어 있습니다 (#132).
- 어떤 규칙 카드(R-xxx)로 판정됐는지는 화면에 나오지 않습니다. 개발자도구에서 `/judgments` 응답의 `ruleCardId` · `appliedRuleIds` 로 볼 수 있습니다.
- 자동으로 분류된 업종은 화면에서 바꿀 수 없습니다. 미분류 가맹점만 「분류 확인」에서 고릅니다. 분류가 틀렸으면 판정을 직접 바꾸는 방법만 있습니다.
