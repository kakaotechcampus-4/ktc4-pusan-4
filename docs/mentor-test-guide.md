# 멘토용 테스트 가이드

PreeT는 1인 프리랜서(업종코드 940909)의 카드 승인내역을 올리면, 거래마다 경비로 넣을 수 있는지 판정하고 근거 조문을 보여주는 서비스입니다.

아래 순서대로 따라가시면 됩니다. 단계마다 확인할 것을 세 가지로 적어 두어서, 세법을 몰라도 잘 만들어졌는지 판단하실 수 있습니다.

- **해 보기**: 직접 눌러 볼 것
- **의미**: 이게 사용자에게 왜 중요한지
- **잘된 것**: 이렇게 나오면 제대로 동작하는 것

| | |
| --- | --- |
| 주소 | https://ktc4-pusan-4.duckdns.org |
| 테스트 계정 · 카드셋 | 따로 전달드립니다 |
| 소요 시간 | 15~20분 |

---

## 1단계. 로그인 · 사업자 문진

1. 전달드린 테스트 계정으로 로그인합니다. 직접 써 보고 싶으시면 로그인 화면의 「이메일로 가입하기」나 「카카오로 계속하기」로 가입하셔도 됩니다.
2. 처음 로그인하면 사업자 문진 화면이 나옵니다. 항목은 자유롭게 골라 주세요. 업종은 현재 「프리랜서, 인적용역」만 고를 수 있습니다.
3. 입력한 **직전연도 수입금액**을 기억해 두세요. 5단계에서 접대비 한도를 확인할 때 씁니다.

> 문진은 나중에 「판정 전 확인」 화면의 「문진 고치기」에서 다시 바꿀 수 있습니다.

---

## 2단계. 카드내역 올리기

전달드린 카드셋 파일을 올립니다. 파일이 없으면 업로드 화면 아래 「샘플 파일로 해 보기」를 눌러도 됩니다. 올리기 전에 미리보기가 나옵니다.

**① 취소된 결제는 알아서 지웁니다**
- **해 보기**: 미리보기에서 결제와 같은 금액의 취소가 있는 행을 찾습니다.
- **의미**: 환불받은 돈이 경비로 잡히지 않습니다. 사용자가 카드내역을 손으로 정리하지 않아도 됩니다.
- **잘된 것**: 두 건이 「취소상계」로 표시되고 판정 대상에서 빠집니다.

**② 판정할 수 없는 행은 이유와 함께 걸러냅니다**
- **해 보기**: 미리보기의 「보내지 않는 행」을 봅니다.
- **의미**: 카드사 파일의 지저분한 행 때문에 합계가 틀어지지 않고, 왜 빠졌는지도 알 수 있습니다.
- **잘된 것**: 0원 결제, 승인일 없음, 가맹점명 없음, 원화 금액 없는 해외 결제가 각각 이유와 함께 빠집니다.

**③ 민감한 정보는 서버로 보내지 않습니다**
- **해 보기**: 병원 · 약국 거래의 가맹점명을 봅니다.
- **의미**: 진료 기록이 드러날 수 있는 정보는 브라우저 밖으로 나가지 않습니다. 카드번호, 이름도 마찬가지입니다.
- **잘된 것**: 가맹점명이 「의료기관 (이름 가림)」으로 바뀌어 있습니다.

**④ 같은 거래를 두 번 넣지 않습니다**
- **해 보기**: 「N건 올리기」를 누른 뒤, 거래가 일부 겹치는 다른 파일(예: KB 샘플 다음 IBK 샘플)을 이어서 올립니다.
- **의미**: 기간이 겹치는 파일을 여러 번 올려도 경비가 부풀려지지 않습니다.
- **잘된 것**: 「중복된 거래 N건은 넣지 않았습니다」가 나옵니다.

---

## 3단계. 판정 실행

「다음: 판정 전 확인」에서 파일과 문진 내용을 확인하고, 안내에 체크한 뒤 「판정 시작」을 누릅니다. 몇 초 안에 끝나고 가능 · 확인 필요 · 불가 건수가 나옵니다.

판정은 세 가지입니다.

| 판정 | 뜻 |
| --- | --- |
| 가능 | 업무 관련 지출이라 경비로 인정 (소득세법 §27①) |
| 불가 | 법이 막거나(§33①) 개인 지출로 보는 경우 |
| 확인 필요 | 사실을 알아야 판단할 수 있어 질문으로 넘김 |

---

## 4단계. 결과 보기

「결과 보기」를 누르고, 거래를 하나씩 눌러 오른쪽 상세를 봅니다.

**⑤ 확실한 것은 바로 인정합니다**
- **해 보기**: 서점 거래(예: 교보문고, 알라딘)를 누릅니다.
- **의미**: 사용자는 정말 판단이 필요한 거래에만 답하면 됩니다.
- **잘된 것**: 가능, 계정과목 도서인쇄비, 근거 소득세법 제27조 제1항이 나옵니다.

**⑥ 법이 막는 지출은 근거 조문과 함께 뺍니다**
- **해 보기**: 의료기관 거래를 누릅니다.
- **의미**: 판정마다 법 조문이 붙어 있어 세무사에게 그대로 근거를 보여줄 수 있습니다. 조문에 시행 기간도 표시돼 어느 시점 법 기준인지 알 수 있습니다.
- **잘된 것**: 불가, 근거 「소득세법 제33조 제1항 제5호」가 나오고 국가법령정보 링크로 원문이 열립니다.

**⑦ 모르는 것은 추측하지 않고 묻습니다**
- **해 보기**: 구독 서비스(넷플릭스), 결제대행(구글플레이), 전자기기(하이마트) 거래를 봅니다.
- **의미**: AI가 그럴듯하게 찍지 않습니다. 틀릴 수 있는 곳은 사용자에게 사실을 확인받고, 그 답으로 규칙이 판정합니다.
- **잘된 것**: 확인 필요로 나오고, 질문 없이 가능이나 불가로 확정되지 않습니다.

**⑧ 개인 지출로 보이는 것은 먼저 빼고 소명 기회를 줍니다**
- **해 보기**: 주말 · 공휴일 카페나 배달 음식 거래를 봅니다.
- **의미**: 문제 되기 쉬운 지출은 보수적으로 처리하되, 실제 업무였다면 살릴 길을 남겨 둡니다.
- **잘된 것**: 불가(답변 대기)로 나오고 「업무 때문이었다면 알려주세요」 안내가 붙습니다.

**⑨ 사용자가 바꾼 판정은 기록으로 남깁니다**
- **해 보기**: 아무 거래에서 「가능으로 바꾸기」(또는 「불가로 바꾸기」)를 누르고 이유를 골라 저장합니다. 확인 후 「수정 되돌리기」를 누릅니다.
- **의미**: 최종 판단은 사람이 하되, 자동 판정과 사람의 판단이 구분되어 남습니다.
- **잘된 것**: 「직접 수정」 표시가 붙고, 판정 이력에 자동 판정과 수정 기록이 함께 남습니다. 되돌리면 원래 판정으로 돌아갑니다.

---

## 5단계. 질문에 답하기

결과 화면의 「질문에 답하기」를 누릅니다.

**⑩ 답하면 그 자리에서 다시 판정합니다**
- **해 보기**: 넷플릭스 질문에 「업무 전용」으로 답합니다.
- **의미**: 답 하나가 경비에 얼마나 영향을 주는지 바로 확인할 수 있습니다.
- **잘된 것**: 새로고침 없이 질문 카드에 「가능」과 경비 가능 금액이 나옵니다.

**⑪ 답에 따라 계정과목까지 정합니다**
- **해 보기**: 주말 카페나 배달 음식 질문에 「거래처 접대」로 답합니다.
- **의미**: 접대비는 한도가 따로 있어서 일반 경비와 나눠야 합니다. 세무사에게 넘길 때 다시 분류할 필요가 없습니다.
- **잘된 것**: 가능으로 바뀌고 계정과목이 기업업무추진비로 잡힙니다.

**⑫ 비싼 기기는 감가상각까지 계산합니다**
- **해 보기**: 하이마트 1,200,000원을 「업무용」으로 답하고, 이어서 나오는 질문에 「자산으로 등재」를 고릅니다.
- **의미**: 같은 지출이라도 처리 방법에 따라 올해 경비가 달라지는 세법 규칙을 그대로 반영합니다.
- **잘된 것**: 「올해 경비로 처리 / 자산으로 등재」 질문이 이어서 나오고, 자산으로 등재하면 올해 경비가 결제액보다 적게(예: 496,100원) 나옵니다.

**⑬ 자택 작업 비율만큼만 경비로 잡습니다**
- **해 보기**: 문진에서 자택 작업 비율을 넣었다면, 전기요금 · 월세 거래를 「자택 겸용」으로 답합니다.
- **의미**: 집과 사무실을 같이 쓰는 프리랜서의 현실을 반영합니다.
- **잘된 것**: 경비 가능 금액이 결제액 × 자택 비율로 나옵니다.

---

## 6단계. 요약 · 내보내기

「요약으로」를 누릅니다.

**⑭ 접대비 한도를 업종에 맞게 계산합니다**
- **해 보기**: 「세무사에게 넘길 문장」의 기업업무추진비 한도를 봅니다.
- **의미**: 일반 공식만 쓰지 않고 국세청 유권해석까지 반영했습니다.
- **잘된 것**: 한도가 1,200만 원 + 문진에 넣은 수입금액 × 0.3%로 나옵니다(예: 8,000만 원 → 12,240,000원). 중소기업 특례 3,600만 원은 940909 면세 인적용역사업자에 적용되지 않으므로 나오지 않아야 합니다. (사전-2025-법규소득-0245)

**⑮ 세무사에게 바로 넘길 수 있게 정리합니다**
- **해 보기**: 계정과목별 금액과 「문장 복사」, 결과 화면의 「CSV 내려받기」를 봅니다.
- **의미**: 사용자가 결과를 다시 정리하지 않고 세무사에게 그대로 전달할 수 있습니다.
- **잘된 것**: 경비 가능 금액이 계정과목별로 나뉘어 있고, 판정 건수 · 금액 · 한도가 한 문단으로 정리됩니다.
