# 멘토용 테스트 가이드

PreeT는 1인 프리랜서(업종코드 940909)의 카드 승인내역을 올리면, 거래마다 경비로 넣을 수 있는지 판정하고 근거 조문을 보여주는 서비스입니다.

세법 도메인이 낯설 수 있어서, 항목마다 아래 세 가지를 적어 두었습니다. 세법을 몰라도 이 기준만 보시면 잘 만들어졌는지 판단하실 수 있습니다.

- **해 보기**: 직접 눌러 볼 것
- **의미**: 이게 사용자에게 왜 중요한지
- **잘된 것**: 이렇게 나오면 제대로 동작하는 것

- 주소: https://ktc4-pusan-4.duckdns.org
- 테스트 계정과 카드셋: 따로 전달드립니다
- 소요 시간: 10~15분

## 1. 진행 순서

1. 카드내역 업로드
2. 분류 확인
3. 사업자 문진
4. 판정 전 확인
5. 결과 확인
6. 질문에 답하기 (답하면 바로 다시 판정됩니다)
7. 요약 · CSV 내려받기

## 2. 문진 입력 예시

로그인하면 사업자 문진 화면이 먼저 나옵니다. 아래 기준표가 이 값을 전제로 하니 그대로 넣어 주세요.

| 항목 | 입력값 |
| --- | --- |
| 업종 | 프리랜서, 인적용역 |
| 직전연도 수입금액 | 80,000,000 |
| 개업일 | 과거 날짜 아무거나 |
| 기장의무 | 자동 선택 (복식부기) |
| 직원 | 없음 |
| 자택 작업 | 예, 20% |

현재 서비스 대상은 복식부기 의무자(직전연도 수입 7,500만 원 이상)입니다. 수입금액을 그보다 적게 넣으면 간편장부가 선택되고 "서비스 대상 밖"으로 표시됩니다.

## 3. 판정은 세 가지입니다

| 판정 | 뜻 | 예 |
| --- | --- | --- |
| 가능 | 업무 관련 지출이라 경비로 인정 (소득세법 §27①) | 도서, 소프트웨어 |
| 불가 | 법이 막거나(§33①) 개인 지출로 보는 경우 | 세금·과태료, 의료비 |
| 확인 필요 | 사실을 알아야 판단할 수 있어 질문으로 넘김 | 구독 서비스, 전자기기, 평일 식대 |

결과 화면에서 거래를 누르면 오른쪽 상세에 업종, 판정 이유, 근거 조문, 경비 가능 금액이 나옵니다.

## 4. 테스트 기준

### 업로드

#### ① 취소된 결제는 알아서 지웁니다

- **해 보기**: 결제와 같은 금액의 취소가 함께 있는 파일을 올립니다.
- **의미**: 환불받은 돈이 경비로 잡히지 않습니다. 사용자가 카드내역을 손으로 정리하지 않아도 됩니다.
- **잘된 것**: 두 건이 「취소상계」로 표시되고 판정 대상에서 빠집니다.

#### ② 판정할 수 없는 행은 이유와 함께 걸러냅니다

- **해 보기**: 업로드 직후 미리보기의 「보내지 않는 행」을 봅니다.
- **의미**: 카드사 파일의 지저분한 행 때문에 합계가 틀어지지 않고, 왜 빠졌는지도 사용자가 알 수 있습니다.
- **잘된 것**: 0원 결제, 승인일 없음, 가맹점명 없음, 원화 금액이 없는 해외 결제가 각각 이유와 함께 빠집니다.

#### ③ 같은 거래를 두 번 넣지 않습니다

- **해 보기**: 거래가 일부 겹치는 다른 카드 파일을 이어서 올립니다.
- **의미**: 기간이 겹치는 파일을 여러 번 올려도 경비가 부풀려지지 않습니다.
- **잘된 것**: 「중복된 거래 N건은 넣지 않았습니다」가 나옵니다.

#### ④ 민감한 정보는 서버로 보내지 않습니다

- **해 보기**: 병원 · 약국 거래가 있는 파일의 미리보기를 봅니다.
- **의미**: 진료 기록이 드러날 수 있는 정보는 브라우저 밖으로 나가지 않습니다. 카드번호, 이름도 마찬가지입니다.
- **잘된 것**: 가맹점명이 「의료기관 (이름 가림)」으로 바뀌어 올라갑니다.

### 판정

#### ⑤ 법이 막는 지출은 근거 조문과 함께 뺍니다

- **해 보기**: 병원 · 약국 거래를 누릅니다.
- **의미**: 판정마다 법 조문이 붙어 있어서 사용자가 세무사에게 그대로 근거를 보여줄 수 있습니다. 조문에는 시행 기간도 표시돼 법이 바뀌어도 어느 시점 기준인지 알 수 있습니다.
- **잘된 것**: 불가, 근거 「소득세법 제33조 제1항 제5호」가 나오고 국가법령정보 링크로 원문을 볼 수 있습니다.

#### ⑥ 확실한 것은 바로 인정합니다

- **해 보기**: 서점 거래(예: 교보문고, 알라딘)를 누릅니다.
- **의미**: 사용자는 정말 판단이 필요한 거래에만 답하면 됩니다.
- **잘된 것**: 가능, 계정과목 도서인쇄비, 근거 소득세법 제27조 제1항이 나옵니다.

#### ⑦ 모르는 것은 추측하지 않고 묻습니다

- **해 보기**: 구독 서비스(넷플릭스), 결제대행(구글플레이), 전자기기 거래를 봅니다.
- **의미**: AI가 그럴듯하게 찍지 않습니다. 판정이 틀릴 수 있는 곳은 사용자에게 사실을 확인받고, 그 답으로 규칙이 판정합니다.
- **잘된 것**: 확인 필요로 나오고 「이 구독은 업무 전용인가요?」 같은 질문이 붙습니다.

#### ⑧ 개인 지출로 보이는 것은 먼저 빼고 소명 기회를 줍니다

- **해 보기**: 주말 · 공휴일 카페나 배달 음식 거래를 봅니다.
- **의미**: 세무조사에서 문제 되기 쉬운 지출을 보수적으로 처리하면서도, 실제 업무였다면 살릴 길을 남겨 둡니다.
- **잘된 것**: 불가(답변 대기)로 나오고 「업무 때문이었다면 알려주세요」 질문이 붙습니다.

#### ⑨ 같은 입력이면 언제나 같은 결과가 나옵니다

- **해 보기**: 같은 파일을 다시 판정합니다.
- **의미**: 판정은 AI가 아니라 규칙 카드가 합니다. 결과를 재현하고 설명할 수 있어서 세무 서비스로 믿을 수 있습니다.
- **잘된 것**: 판정이 전부 똑같이 나옵니다.

### 질문에 답하기

#### ⑩ 답하면 그 자리에서 다시 판정합니다

- **해 보기**: 「답할 질문」에서 넷플릭스를 「업무 전용」으로 답합니다.
- **의미**: 사용자는 답 하나가 경비에 얼마나 영향을 주는지 바로 확인할 수 있습니다.
- **잘된 것**: 질문 카드에 바로 「가능」과 경비 가능 금액이 나오고, 결과 화면 합계도 바뀝니다.

#### ⑪ 답에 따라 계정과목까지 정합니다

- **해 보기**: 주말 카페 질문에 「거래처 접대」로 답합니다.
- **의미**: 세무사에게 넘길 때 다시 분류할 필요가 없습니다.
- **잘된 것**: 가능으로 바뀌고 계정과목이 기업업무추진비로 잡힙니다.

#### ⑫ 비싼 기기는 감가상각까지 계산합니다

- **해 보기**: 하이마트 1,200,000원을 「업무용」으로 답한 뒤 이어지는 질문에 「자산으로 등재」를 고릅니다.
- **의미**: 같은 지출이라도 처리 방법에 따라 올해 경비가 달라지는 세법 규칙을 그대로 반영합니다.
- **잘된 것**: 올해 경비가 결제액보다 적게(예: 496,100원) 나옵니다. 360,000원짜리 기기는 결제액 전체가 경비로 나옵니다.

#### ⑬ 자택 작업 비율만큼만 경비로 잡습니다

- **해 보기**: 문진에서 자택 작업 20%를 넣고, 전기요금 · 월세 거래를 「자택 겸용」으로 답합니다.
- **의미**: 집과 사무실을 같이 쓰는 프리랜서의 현실을 반영합니다.
- **잘된 것**: 경비 가능 금액이 결제액의 20%로 나옵니다.

### 요약 · 수정

#### ⑭ 접대비 한도를 업종에 맞게 계산합니다

- **해 보기**: 요약 화면의 「세무사에게 넘길 문장」을 봅니다.
- **의미**: 일반 공식만 쓰지 않고, 국세청 유권해석까지 반영했습니다.
- **잘된 것**: 한도가 12,240,000원(1,200만 원 + 수입금액 × 0.3%)으로 나오고, 36,000,000원은 나오지 않습니다. 중소기업 특례(3,600만 원)는 940909 면세 인적용역사업자에 적용되지 않기 때문입니다. (사전-2025-법규소득-0245)

#### ⑮ 사용자가 바꾼 판정은 기록으로 남깁니다

- **해 보기**: 결과 상세에서 「가능으로 바꾸기」를 누르고 이유를 골라 저장합니다.
- **의미**: 최종 판단은 사람이 하되, 자동 판정과 사람의 판단이 구분되어 남습니다.
- **잘된 것**: 「직접 수정」 표시가 붙고, 판정 이력에 자동 판정과 수정 기록이 함께 남습니다. 「수정 되돌리기」로 원래대로 돌릴 수 있습니다.

## 5. 알려진 한계

문제로 보이실 수 있지만 현재 의도된 상태입니다.

- 가능 판정에는 이유 문장 없이 근거 조문만 나옵니다. (#132)
- 어떤 규칙 카드로 판정됐는지는 화면에 나오지 않습니다. 개발자도구에서 `/judgments` 응답의 `ruleCardId`로 볼 수 있습니다.
- 자동 분류된 업종은 화면에서 바꿀 수 없습니다. 분류가 틀리면 판정을 직접 수정해야 합니다.
- 수입금액은 가능 · 불가 판정에 영향이 없고 접대비 한도만 바꿉니다.
