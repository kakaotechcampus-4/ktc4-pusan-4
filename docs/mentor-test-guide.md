# 멘토용 테스트 가이드

PreeT는 1인 프리랜서(업종코드 940909)의 카드 승인내역을 올리면, 거래마다 경비로 넣을 수 있는지 판정하고 근거 조문을 보여주는 서비스입니다.

세법 도메인이 낯설 수 있어서, 각 항목마다 **이렇게 나오면 정상, 이렇게 나오면 문제**를 적어 두었습니다. 이 기준대로만 보셔도 제대로 동작하는지 판단하실 수 있습니다.

- 주소: https://ktc4-pusan-4.duckdns.org
- 테스트 계정과 카드셋: 따로 전달드립니다
- 소요 시간: 10~15분

## 1. 진행 순서

1. 카드내역 업로드
2. 분류 확인
3. 사업자 문진
4. 판정 전 확인
5. 결과 확인
6. 질문에 답하기 (답하면 바로 다시 판정됩니다)
7. 요약 · CSV 내려받기

## 2. 문진 입력 예시

로그인하면 사업자 문진 화면이 먼저 나옵니다. 아래 기준표가 이 값을 전제로 하니 그대로 넣어 주세요.

| 항목 | 입력값 |
| --- | --- |
| 업종 | 프리랜서, 인적용역 |
| 직전연도 수입금액 | 50,000,000 |
| 개업일 | 과거 날짜 아무거나 |
| 기장의무 | 자동 선택 (간편장부) |
| 직원 | 없음 |
| 자택 작업 | 예, 20% |

## 3. 판정은 세 가지입니다

| 판정 | 뜻 | 예 |
| --- | --- | --- |
| 가능 | 업무 관련 지출이라 경비로 인정 (소득세법 §27①) | 도서, 소프트웨어 |
| 불가 | 법이 막거나(§33①) 개인 지출로 보는 경우 | 세금·과태료, 의료비 |
| 확인 필요 | 사실을 알아야 판단할 수 있어 질문으로 넘김 | 구독 서비스, 전자기기, 평일 식대 |

결과 화면에서 거래를 누르면 오른쪽 상세에 업종, 판정 이유, 근거 조문, 경비 가능 금액이 나옵니다.

## 4. 테스트 기준

### 업로드

| 해 볼 것 | 정상 | 문제 |
| --- | --- | --- |
| 결제와 같은 금액 취소가 함께 있는 파일 | 둘 다 판정 대상에서 빠짐 | 결제나 취소가 결과에 남음 |
| 0원 · 포인트 사용 행 | 판정 대상에서 빠짐 | 결과에 0원 거래가 보임 |

### 분류와 판정

| 해 볼 것 | 정상 | 문제 |
| --- | --- | --- |
| 서점 거래 (예: 교보문고) | 업종 도서, 가능, 근거 §27① | 다른 업종으로 분류되거나 불가 |
| 병원 · 약국 거래 | 불가, 근거 §33① (가사 관련 경비) | 가능이나 확인 필요 |
| 구독 서비스 (예: 넷플릭스) | 확인 필요 + 업무 전용인지 묻는 질문 | 질문 없이 바로 가능이나 불가 |
| 주말 · 공휴일 카페나 식당 | 불가 + 거래처 미팅이었는지 묻는 질문 | 바로 가능 |
| 같은 파일을 다시 판정 | 판정이 전부 똑같이 나옴 (규칙 엔진이 판정) | 돌릴 때마다 결과가 다름 |

### 질문에 답하기

| 해 볼 것 | 정상 | 문제 |
| --- | --- | --- |
| 구독 서비스를 "업무 전용"으로 답함 | 바로 가능으로 바뀜 | 안 바뀌거나 새로고침해야 바뀜 |
| 주말 카페를 "업무 미팅"으로 답함 | 가능, 접대비로 분류 | 불가 그대로 |
| 전기요금 · 월세를 "자택 겸용"으로 답함 | 경비 금액 = 결제액 × 20% | 결제액 전체가 경비로 잡힘 |
| 100만 원 넘는 전자기기를 "자산으로 등재" | 올해 경비가 결제액보다 적음 (감가상각) | 결제액 전체가 올해 경비 |
| 100만 원 이하 전자기기를 업무용으로 답함 | 결제액 전체가 올해 경비 (즉시상각) | 감가상각으로 나뉨 |

### 요약

| 해 볼 것 | 정상 | 문제 |
| --- | --- | --- |
| 접대비 한도 | 12,150,000원 (1,200만 원 + 수입금액 × 0.3%) | 36,000,000원 (중소기업 특례는 940909에 적용되지 않음, 사전-2025-법규소득-0245) |
| 결과 상세에서 판정 직접 수정 | "직접 수정" 표시와 이력이 남음 | 표시 없이 바뀌거나 이력 없음 |
| CSV 내려받기 | 화면의 판정 · 금액과 같은 내용 | 화면과 값이 다름 |

## 5. 알려진 한계

문제로 보이실 수 있지만 현재 의도된 상태입니다.

- 가능 판정에는 이유 문장 없이 근거 조문만 나옵니다. (#132)
- 어떤 규칙 카드로 판정됐는지는 화면에 나오지 않습니다. 개발자도구에서 `/judgments` 응답의 `ruleCardId`로 볼 수 있습니다.
- 자동 분류된 업종은 화면에서 바꿀 수 없습니다. 분류가 틀리면 판정을 직접 수정해야 합니다.
- 수입금액은 가능 · 불가 판정에 영향이 없고 접대비 한도만 바꿉니다.
