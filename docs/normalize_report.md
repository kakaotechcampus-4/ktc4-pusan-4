### 왜 `>= 20` 이 아니라 `== 20` 인가

`>= 20` 으로 두면 20바이트를 초과하는 정상 입력까지 절단으로 오판해
지점명 제거가 동작하지 않는다. 카드사가 20에서 자르므로 그보다 긴 문자열은
애초에 들어오지 않는다.

실제로 첫 구현에서 `>=` 로 뒀다가 `스타벅스코리아 강남대로점`(25바이트)이
절단으로 판정돼 `스타벅스강남대로점` 이 나왔다. 조건을 바꾸려면 이 케이스를 먼저 볼 것.

### 절단으로 갈라진 문자열이 사업자번호로 다시 묶인 사례

- `107-86-***47` ← `코레일유통(주)서부지` / `코레일유통주식회사(`

트랙 1을 최우선에 둔 이유다. 문자열만으로는 같은 회사인지 알 수 없다.

## 3. 축약 충돌 후보

서로 다른 원문이 같은 문자열 키로 합쳐지는 경우다.

- `GS25` ← `GS25부산의대학사점` / `GS25양산스타점`

합쳐지는 것이 **맞는** 경우(같은 브랜드의 다른 지점)와 **틀린** 경우(다른 가맹점)를 구분해야 한다. 위 목록은 전부 같은 브랜드의 다른 지점이고,
각각 사업자번호가 달라 트랙 1에서는 별개로 유지된다. 문자열 키로 합쳐지는 것은 브랜드 단위 분류(카테고리)를 위해서다.

### `min_keep` 가드에 막혀 지점명을 제거하지 못한 상호

전부 한글이라 지점 토큰만 떼어낼 수 없는 경우다. 통째로 사라지는 것보다 안 줄이는 쪽이 안전하다고 판단했다.

- `씨유범어그린점` → `씨유범어그린점`
- `씨유센텀동서점` → `씨유센텀동서점`
- `씨유수비사거리점` → `씨유수비사거리점`
- `아웃닭범어점` → `아웃닭범어점`

이 상호들은 전부 사업자번호가 있어 트랙 1로 처리된다. 브랜드 사전(T4)이 생기면 다시 볼 항목이다.

## 4. 해외 결제 판정

판정 기준: 사업자번호 없음 **AND** 영문 글자 비율 50% 이상.

| 원문 | 정규화 결과 | 별표 토큰 |
|---|---|---|
| `AMAZON PAY INDIA PRIVA` | `AMAZONPAYINDIAPRIVA` | — |
| `ANTHROPIC* CLA` | `ANTHROPIC\|CLA` | `ANTHROPIC` + `CLA` |
| `CLAUDE.AI SUBS` | `CLAUDEAISUBS` | — |
| `NETFLIX_INICIS` | `NETFLIXINICIS` | — |
| `OPENAI *CHATGPT SUBSCR` | `OPENAI\|CHATGPTSUBSCR` | `OPENAI` + `CHATGPT SUBSCR` |
| `PYU*Amazon Seller Serv` | `PYU\|AMAZONSELLERSERV` | `PYU` + `Amazon Seller Serv` |
| `Steam (Korea)` | `STEAMKOREA` | — |

**7개 상호 / 8건**.

### 같은 서비스인데 키가 갈라지는 경우 — 정상이다

```
ANTHROPIC* CLA  -> ANTHROPIC|CLA
CLAUDE.AI SUBS  -> CLAUDEAISUBS
```

둘 다 같은 서비스 결제인데 문자열이 전혀 겹치지 않는다. **정규화로 풀 수 없다.**
문자열을 더 깎아 억지로 붙이면 관계없는 가맹점까지 합쳐진다.
이건 되묻기 한 번 + 학습 룰카드가 처리할 영역이고, 정규화 단계에서는
서로 다른 키로 두는 것이 맞다.

`*` 는 양쪽 토큰을 모두 보존한다. 어느 쪽이 결제대행사인지 문자열만으로는
결정되지 않기 때문이다 — `ANTHROPIC*CLA` 는 앞이 서비스명이고,
`PYU*Amazon Seller Serv` 는 앞이 PG(PayU)다. 한쪽을 버리는 규칙은 만들지 않았다.

## 6. 남은 문제

- 사업자번호 없는 47건은 문자열 키에 의존한다. 절단된 상호가 여기 섞이면 같은 가맹점이 여러 키로 갈린다.
- `교통-버스1건` 처럼 카드사가 여러 건을 합산해 만든 행은 가맹점이 아니다. 정규화 대상에서 빼야 할지 T2/T3에서 다시 본다.
- 해외 표본이 7건뿐이다. 판정 기준(영문 비율)은 표본이 늘면 다시 재야 한다.
