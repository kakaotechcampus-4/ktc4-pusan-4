# 카테고리 분류: 해외 결제 — 도구 사전 매칭

측정일 2026-10-01, PR #73 리뷰 반영 후 재측정 2026-10-05. 재현: `tools/exp_overseas_saas/README.md`.
가맹점 데이터셋 매칭(`docs/merchant_matching_eval.md`, PR #61)은 상권정보(오프라인 점포)라 해외 SaaS 커버리지가 0%다.
그 빈칸을 SaaS 목록 사전으로 채운다. 구조는 같다 — **사전으로 확정, 못 찾으면 되묻기.**

## 방식

```
결제 문구 → 키워드룰(rules/keyword_rules.yaml) → 도구 사전(dict.csv)
   ├ 사전에 있음 → 해외SaaS·게임 자동 확정
   └ 없음 → 결제대행만 보이면 PG_미상, 아니면 미분류(분류 확인 → 사용자가 후보 중 선택, api.md 2.4)
```

- 은행 문구·결제대행 접두어(`PAYPAL *`, `PADDLE.NET*`, `GOOGLE *` 등)를 떼고 브랜드 부분만 본다.
- 도메인형(`GITHUB.COM`)은 강한 증거. 토큰형은 흔한 영단어면 브랜드 첫 토큰일 때만 인정한다.
- `GOOGLE`·`MICROSOFT`·`AMAZON` 같은 우산 브랜드는 회사 이름만으로 확정하지 않는다. 뒤에 붙은 제품 이름으로 판단한다.
  키워드룰이 사전보다 먼저 이기므로 키워드룰도 같은 원칙을 따른다 — 회사명 단독 룰을 두지 않는다(`MICROSOFT` 룰을 제품명만 남기도록 고침).
- 사전 키는 상품명과 도메인 첫 라벨에서 뽑는다. 첫 라벨이 흔한 영단어(`cloud.google.com` → `CLOUD`)거나 호스팅 계정명(`facebook.github.io`)이면 키로 쓰지 않는다. 그 단어로 시작하는 엉뚱한 결제가 해외SaaS 로 잡히기 때문이다(사전 755 → 748개).

## 결과 (평가 94건, 해외SaaS 46건)

자동 확정 = 사용자 분류 없이 카테고리가 정해진 것(미분류·PG_미상 제외).

| | 자동 확정 | 확정 정확도 | 도구 재현율 |
|---|---|---|---|
| A 키워드룰만 | 37 | 37/37 | 24/46 (52%) |
| **B 키워드룰 + 사전** | **52** | **52/52** | **39/46 (85%)** |
| C 사전만 | 45 | 45/45 | 34/46 (74%) |

- 사전을 붙이면 도구 재현율이 52% → 85%로 오르고, 확정한 52건에 오답이 없다.
- 리뷰 반영 전(B: 54건 확정, 53/54, 재현율 40/46)과 달라진 2건:
  - `MICROSOFT *XBOX MSBILL.INFO`(게임): `MICROSOFT` 룰에 걸려 해외SaaS 로 잘못 확정되던 것 → 미분류. 오답 1건이 사라졌다.
  - `Google*Cloud m44pzq`(해외SaaS): 사전 키 `CLOUD` 로 맞히던 것 → PG_미상. `CLOUD` 키가 다른 결제를 잘못 잡을 위험과 맞바꾼 것이라, 재현율 1건을 내줬다.

## 놓친 것 (B 기준 도구 7건 + 게임)
- 대행사 뒤 이름이 사전 형태와 다름: `GOOGLE *ZOOMdotUS`, `GOOGLE *Workspace_1871` → PG_미상
- 대행사 뒤 이름이 흔한 영단어: `Google*Cloud m44pzq` → PG_미상 (키워드룰 `GOOGLE\s*CLOUD` 는 사이의 `*` 때문에 안 걸림)
- 사전에 없는 소규모 도구: `PADDLE.NET* GETASTRA`, `PADDLE.NET* - CLASSMARKR` → PG_미상
- 잘린 이어붙임·청구 도메인만 있음: `DROPBOXINTE`, `MSFT *<...> MSBILL.INFO` → 미분류
- 게임사(Steam·Epic·Riot·Blizzard·Xbox 등)는 사전에 없어 미분류로 간다.

## 모르는 해외 결제를 구독서비스가 아니라 미분류로 보내는 이유
1차 실험은 모르는 해외 결제를 구독서비스로 넘겨짚고 용도를 되물었다. 그러면 게임 8건이 구독서비스로 확정되고
'업무 관련 구독인가'라는 엉뚱한 질문을 받는다. 미분류로 두면 분류 확인에서 사용자가 카테고리를 고른 뒤
그 카테고리의 질문을 받는다. B 기준 미분류 23건(정답: 구독서비스 12 · 게임 9 · 해외SaaS 2)이 이 경로로 간다.
