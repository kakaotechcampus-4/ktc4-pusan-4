## 2. matched_suffix 확보율

차단된 상호 중 **5/9 (55.6%)** 에서 PG 가 아닌 토큰을 하나 이상 건졌다.
이 토큰이 되묻기 화면의 힌트가 된다 — 사용자가 "이게 뭐였지" 를 덜 겪는다.

| 상호 | PG 토큰 | 힌트 (matched_suffix) |
|---|---|---|
| `NETFLIX_INICIS` | `INICIS` | `NETFLIX` |
| `PYU*Amazon Seller Serv` | `PYU` | `Amazon Seller Serv` |
| `다날_대표-그렙` | `다날` | `그렙` |
| `카카오선물하기_카카오페이-주식회사카카오` | `카카오페이` | `카카오선물하기`, `카카오` |
| `토스페이_요기요-(주) 비바리퍼블리카` | `토스페이`, `비바리퍼블리카` | `요기요` |

## 3. 힌트 없는 케이스

전체 토큰이 PG 라서 남는 게 없다. 되묻기 화면에 보여줄 단서가 상호명뿐이다.

| 상호 | 걸린 패턴 |
|---|---|
| `KIS정보통신-KIS정보통신` | `KIS정보통신` |
| `구글플레이` | `구글플레이\|구글페이먼트코리아\|GOOGLE\s*PAY(MENT)?` |
| `나이스정보통신` | `나이스페이\|나이스정보통신\|NICEPAY` |
| `섹타나인_코페이_비인증_일반-주식회사 코페이` | `섹타나인\|코페이` |

이 경우 금액·날짜 외에는 단서가 없다. KB 파일의 사용자 메모 컬럼이
유일하게 남은 단서라서(구글플레이 -> Onedrive/Gemini/GPT) 되묻기 화면에
메모를 같이 띄우는 것이 좋겠다.

## 4. PG 가 아니라고 판단한 것

PG 처럼 보이지만 "뒤에 뭐가 붙어도 카테고리가 안 변하는" 것들이다.
차단하면 매달 반복되는 확정 지출이 매달 되묻기로 간다.

| 상호 | 이유 | 처리 |
|---|---|---|
| `배민클럽_우아한형제들-배민클럽_우아한형제들` | 배달의민족 구독. 우아한형제들 자체 상품 | 차단 안 됨 (확인) |
| `삼성닷컴_청구-삼성전자(주)` | 삼성 자체 청구 | 차단 안 됨 (확인) |
| `구글클라우드코리아` | GCP. 실제 서비스명 | 차단 안 됨 (확인) |

## 5. PM 판단 필요

### 카카오페이 / 네이버페이

- 질문: 뒤에 가맹점명이 붙어 오는 비율이 얼마인가. 붙어 오면 그 토큰으로 분류할 수 있다
- 현재 처리: 차단하고 남은 토큰을 matched_suffix 로 남긴다
- 실증: 카카오선물하기_카카오페이-주식회사카카오 -> 힌트로 카카오선물하기 확보

### Steam (Korea)

- 질문: 카드 전표에 KOMOJU 가 찍히는 경우가 있는지. 현재 문자열에는 안 나온다
- 현재 처리: 차단되지 않는다. 해외 트랙으로 가서 T3 키워드룰이 받는다

### 다날

- 질문: '다날' 은 짧아서 다른 상호에 들어갈 수 있다 (예: 가상의 '다날식당')
- 현재 처리: 그대로 둔다. 현재 데이터에서 오탐 0건
