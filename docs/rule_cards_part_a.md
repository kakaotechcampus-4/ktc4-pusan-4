## 스키마에서 달라진 것

이전 초안은 `reason` · `attributes` · `evidence` 를 썼습니다. 11개 필드 확정으로 셋 다 삭제됐습니다.

- `reason` → 카드 헤더 주석으로 옮겼습니다. 판정 문구는 화면 쪽에서 만듭니다.
- `attributes` → 되묻기 선택지의 effect 로 옮겼습니다. `options[]` 에서 `value`·`verdict`·`account` 를
  뺀 나머지 키가 판정 속성이 되는 경로입니다(R-240·R-241·R-242).
- `evidence` → 증빙은 G5 R-060 이 되묻습니다. A 파트 카드에서는 뺐습니다.
- `citations` 는 `{ id, verified }` 객체입니다. **원문을 확인하지 못한 조문에는 `verified` 를 달지 않았습니다** —
  시행령 §62 · §67④ · 법 §39 · §33①14 가 그렇습니다.
