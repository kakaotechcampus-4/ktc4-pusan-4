# 멘토용 테스트 가이드

## 한 일

- `docs/mentor-test-guide.md` 작성: 흐름, 사업자 문진 입력 예시, 샘플 카드셋과 예상 판정, 체크 포인트, 분류 · 판정 확인 기준
- 멘토 테스트에서 나온 두 불편을 짚음
  - 「전년도 소득액」→ 실제 칸은 「직전연도 수입금액」(매출 기준)이고, 판정이 아니라 접대비 한도만 바꾼다는 점을 명시
  - 판정 근거 → 상세 패널의 업종 · 판정 이유 · 근거 조문 위치와, 가능 판정엔 이유 문장이 없는 현재 한계를 적음
- 테스트 계정 정보는 저장소에 넣지 않음

## 남은 일

- 샘플 거래의 「예상 판정」은 규칙 카드 · 키워드 사전에서 도출한 값이라 실서버 결과와 한 번 대조 필요
- 최종 발표 페이지 제출 여부 결정

## 수정 (2026-11-08)

- 테스트용 카드셋 섹션 제거 (카드셋은 PM이 따로 준비)
- 문장을 짧게 다듬고 강조·꺾쇠 표기를 줄여 가독성 정리
- 확인 항목을 "해 볼 것 / 정상 / 문제" 기준표로 바꿈 (도메인이 낯선 평가자가 바로 판단할 수 있게)
- 실서버(테스트 계정, KB·IBK 샘플)로 기준표 대조: 수입금액 예시 8,000만(복식부기 대상), 접대비 한도 12,240,000, 전자기기 질문 흐름, 중복 업로드·결제대행 행 추가
- 테스트 기준을 항목별 "해 보기 / 잘된 것 / 완벽한 것 / 의미" 형식으로 개편 (강점이 드러나게)
- "완벽한 것" 항목 제거, 순서를 해 보기 → 의미 → 잘된 것으로 변경

## 수정 (2026-11-09, 이슈 #277 의견 반영)

- 로그인 후 따라가는 단계형(1~6단계)으로 재구성
- 회원가입 · 로그인 안내 추가, 문진은 자유 선택(수입금액 드롭다운 전환 예정)
- 알려진 한계 섹션 삭제, 미검증인 재판정 일관성 항목 제거
