## 왜 이렇게 했나

- GIF 원본이 25MB 라 가로 960px, 약 8fps 애니메이션 WebP(1.32MB)로 줄여 base64 로 넣었다. 스크롤 영상이라 프레임마다 화면이 달라 중복 프레임을 합쳐 줄일 수 없었다. `index.html` 은 1.15MB → 2.9MB 가 됐다.
- 룰셋은 GitHub API 로 확인했다. develop · release 는 승인 1명 이상, main 은 강제 push · 삭제 금지만 있다(11/9 변경).
