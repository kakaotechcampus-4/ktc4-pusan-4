# 좁은 폭에서 헤더 글자가 음절 단위로 꺾이던 것을 고쳤다

- 브랜치: feature/account
- 커밋: 6c6a930 (1개)
- 주요파일: frontend/src/components/AppShell.tsx

## 한 일

- 헤더 한 줄에 `whitespace-nowrap` 을 주고, 로고 · 단계 표시 · 자료 링크 · 로그아웃은 줄어들지 않게(`shrink-0`) 했다
- 폭이 모자라면 덜 중요한 것부터 접는다
  - 1280px 미만: 지금 단계가 아닌 단계는 번호 · 체크만 보인다. 이름은 `sr-only` 와 `title` 로 남긴다
  - 1024px 미만: 귀속 연도를 숨기고, 이메일 링크 대신 내 정보 아이콘 링크(`aria-label` 에 이메일)를 둔다
  - 768px 미만: 지금처럼 단계 표시를 숨긴다

## 왜 이렇게 했나

- 헤더를 폭을 재 보니 로고 84px · 단계 표시 477px · 오른쪽 묶음 478px 에 좌우 여백 48px 이라 약 1,090px 가 필요했다. 어느 항목도 줄어들 수 없게 막혀 있지 않아서, 768px(단계 표시가 나타나는 폭)부터 약 1,090px 사이에서 브라우저가 항목을 눌러 한글을 음절마다 꺾었다
- 줄바꿈만 막으면 넘쳐서 로그아웃이 화면 밖으로 밀린다. 그래서 접는 순서를 정했다 — 지금 단계 이름은 끝까지 남기고, 다른 단계 이름 → 귀속 연도 → 이메일 글자 순으로 접는다. 이메일은 내 정보로 가는 유일한 링크라 숨기지 않고 아이콘으로 바꿨다

## 확인

- 1440 · 1280 · 1279 · 1100 · 1040 · 1023 · 900 · 800 · 768 · 767 · 700 · 640 · 639 · 414 · 375 · 360px 에서 줄바꿈 0, 헤더 넘침 0
- 아이콘 링크로 `/account` 에 들어가고 `aria-current="page"` 가 붙는다. 체크로 접힌 단계도 이름을 읽는다
- `npm run build` · `npm run lint`(경고 10건은 기존 파일) 통과

## 남은 것 · 아는 문제

- 320px 에서는 로그아웃 버튼이 오른쪽 여백 안으로 21px 들어간다(화면 밖으로 나가지는 않는다). 이 폭에서는 본문도 이미 16px 넘친다
- 640px 미만에서는 여전히 내 정보 링크가 없다(전부터 그랬다). 넣으려면 모바일 메뉴가 필요하다
- `REFS` 에 링크를 더하면 위 폭 계산이 바뀐다. 더할 때는 768 · 1024 · 1280px 에서 한 줄에 들어가는지 다시 본다
