## 13:20 로고로 대화 사라짐, 도움말 순서, 보내는 이력·연도, 패널이 가리는 선택지

- 커밋: d89ea57
- 10/18 화면 점검(목, Chrome)에서 재현한 것들이다
- **로고로 대화 사라짐** — Provider 가 로그인 뒤 레이아웃(`SignedIn`) 안에 있어 `/` 로 가면 내려갔다(대화 4개 → 0개). `BrowserRouter` 바로 안의 `AssistantRoot` 로 올리고 `key={email}` 을 준다
  - 계정이 바뀌거나 로그아웃하면 key 가 바뀌어 대화가 사라진다. 전의 「로그아웃하면 레이아웃과 함께 사라진다」를 key 로 지킨 것
  - 버튼·패널(`Assistant`)은 `SignedIn` 에 남겨 로그인 뒤 화면에만 그린다. `RequireAuth` 가 자식 하나를 받아 fragment 로 싼다
- **문답 순서** — 보내 놓고 도움말을 누르면 「나: 용어」「나: 확인 필요」「Really: 확인 필요는…」「Really: (용어의 답)」처럼 엇갈렸다. 기다리는 동안 도움말·다음 할 일 버튼을 막고 콜백도 돌아간다
  - 다음 할 일은 묻는 말을 먼저 붙이고, 진행 상황을 읽는 동안 `pending` 을 세운다. 전에는 응답이 온 뒤에 묻는 말과 답을 함께 붙여, 그사이 보낸 말이 앞에 끼었다
- **보내는 이력** — 도움말·다음 할 일 문답에 `local` 을 달고 `historyOf` 가 뺀다. 비서가 하지 않은 말을 비서의 말로 넘기고, 순서가 섞이면 user·user·assistant·assistant 로 갔다. 긴 도움말 문구가 20개 한도도 차지했다
- **연도** — `context.year` 를 2026 으로 보낸다(명세 9장 예시, 머리글 「귀속 2026년」). 상수는 Provider 에 두었다. 머리글(AppShell)은 #151 이 다시 짜고 있어 함께 바꾸지 않았다
- **Retry-After 0** — 「0초 뒤에 다시 물어봐 주세요」 대신 시간을 모를 때의 문구
- **패널이 가리는 선택지** — 1280px 에서 패널(오른쪽 25rem)이 질문 카드 오른쪽 선택지를 덮었다. 1024px 이상에서 열려 있으면 `body` 에 오른쪽 여백(27.75rem)을 주어 가운데 놓인 화면이 비킨다. 닫거나 로그인 뒤 화면을 떠나면 지운다
  - 모달의 스크롤바 보정과 같은 방식이다. AppShell 을 건드리지 않아 #151 과 부딪히지 않는다
  - 아래쪽 여백(떠 있는 버튼이 맨 아래 줄을 가리는 것)도 넣어 봤지만 `html`·`body` 가 높이 100% 라 여백이 문서 끝이 아니라 첫 화면 아래에 생겨 뺐다. 스크롤 중에 떠 있는 버튼이 가리는 것은 떠 있는 버튼의 성질이다
- 테스트: `logic.test.ts` 에 `historyOf`(혼자 답한 문답을 빼고 남은 말에서 20개), Retry-After 0
- 확인: `npm run build`·`npm run lint`(오류 0, 기존 경고 10)·`npm test`(136 통과, 7 건너뜀). 목업에서
  - 도움말 → 보내기 → 기다리는 동안 도움말 버튼 막힘, 순서 그대로, 보낸 요청의 `year` 2026·`history` 빈 배열(도움말 문답 빠짐)
  - 로고 → 랜딩(버튼 안 보임) → 결과로 돌아오면 대화 5개 그대로, 다른 계정으로 로그인하면 빈 대화
