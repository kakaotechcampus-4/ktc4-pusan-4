## 한 일

Jaeseong22 리뷰 네 가지를 고쳤다.

- **다른 계정으로 로그인하면 앞 사람 데이터가 남던 것** — `signIn` 이 로그인 전에 세션(사용자·배치·문진·실행)을 비운다. http 로그인도 보내기 전에 앞 토큰을 버린다
- **재발급 5xx·연결 끊김에도 로그인이 풀리던 것** — 재발급이 401 일 때만 `onLost`. 그 밖에는 토큰을 두고 그 오류로 요청을 끝내고, 다음 요청이 다시 재발급한다. `restore` 는 어떤 실패든 false
- **관리자 목록 마지막 쪽이 비면 갇히던 것** — 쪽이 비면 첫 쪽으로 간다(업로드 이력·거래와 같은 방식)
- **목이 401 을 안 내던 것** — 목 로그인은 비밀번호 `demo1234` 만 받고(이메일은 무엇이든, `admin@…` 은 관리자), 로그인 전·로그아웃 뒤 `users.me` 는 401. 로그인 화면의 목업 전용 버튼이 이 값을 보내고, 목업일 때만 한 줄로 알린다
- 테스트: http 3건(재발급 503 은 로그인 유지·다음 요청에서 이어 감, restore 는 503·연결 끊김 모두 false, 다른 계정 로그인 실패 뒤 토큰 없음), 목 1건(틀린 비밀번호·로그인 전·로그아웃 뒤 401)

## 왜 이렇게 했나

- `/login` 가드 대신 `signIn` 에서 비운 것: 리뷰가 제안한 자리다. 가드를 두면 로그인한 채로는 다른 계정으로 바꿀 수 없다. 비우면 바꾸기가 그대로 된다
- 로그인 실패 때 앞 사람의 서버 로그아웃을 부르지 않은 것: 로그아웃 응답의 쿠키 지우기(`Max-Age=0`)가 새 로그인의 쿠키보다 늦게 오면 새 쿠키를 지운다
- 목 비밀번호를 `demo1234` 로 한 것: #155 로컬 프로필의 고정 사용자 비밀번호와 같아 목·로컬 서버를 같은 값으로 오간다. 값은 `api/index.ts` 의 `mockPassword` 로만 화면에 나간다(목업일 때만 값이 있다). http 빌드에 이 문자열이 없는 것을 확인했다

## 13:14 재발급 경합, 관리자 모달 문구·쪽 번호

- 커밋: a8488f6, c0d8668
- 10/18 점검(이전 워크플로의 재현 P1~P4)에서 확인한 경합을 막았다. 모두 「그사이 세션이 바뀌었는데 지난 응답이 지금 세션에 쓰인다」 꼴이다
  - 재발급 중 로그아웃 → 늦은 토큰이 되살아난다(Set-Cookie 도 다시 심긴다)
  - 재발급 중 다른 계정 로그인 → 앞 사람 토큰이 새 토큰을 덮고, 앞 사람 요청이 새 토큰으로 다시 간다
  - 앞 세션 재발급 401 → 새 로그인이 풀린다
  - 이미 바뀐 토큰으로 보낸 요청의 늦은 401 → 재발급을 한 번 더 한다
  - 이어 가기 중 로그인 → 늦은 결과가 「로그인 전」으로 덮는다. `start()` 의 최근 업로드가 계정을 바꾼 뒤 오면 앞 사람 배치가 들어간다
- **http.ts 세대 번호** — 로그인·로그아웃·풀림마다 올린다. 재발급은 시작할 때의 번호와 같을 때만 토큰을 쓰고, 요청의 401 은 보낼 때의 번호와 같을 때만 재발급·재시도·풀림으로 이어진다. 다르면 그 401 을 그대로 올린다
  - 보낸 토큰과 지금 토큰이 다르면 재발급 없이 다시 보낸다
  - 로그인·로그아웃은 진행 중인 재발급이 끝난 뒤에 보낸다. 서버는 응답 순서대로 쿠키를 덮으므로, 재발급 응답이 더 늦으면 지난 리프레시 쿠키가 남는다
  - 로그아웃은 재발급이 없으면 전처럼 토큰을 실어 바로 보내고, 있으면 토큰 없이 끝난 뒤에 보낸다. #155 의 로그아웃은 본문·토큰 없이 쿠키만 지운다
- **SessionContext 번호** — `clear()` 마다 올린다. 이어 가기·로그인 뒤 내 정보·최근 업로드 응답은 시작할 때 번호와 같을 때만 쓴다. 내 정보를 못 읽어 로그아웃할 때도 세션이 그대로일 때만 한다
- **관리자** — 모달을 취소·Esc 로 닫으면 실패 문구를 지운다(전에는 페이지 아래로 옮겨 붙었다). 목록 오류일 때 쪽 번호를 숨긴다
- 테스트: `http.test.ts` 에 경합 다섯 가지. 재발급 응답을 붙잡아 두고 로그인·로그아웃을 끼운다. 바꾸기 전 `http.ts` 로 돌리면 다섯 개 모두 실패한다
