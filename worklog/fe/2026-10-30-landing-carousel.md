# 랜딩에 가로로 넘겨 보는 예시 카드를 넣었다

- 브랜치: feat/landing-carousel
- 주요파일: frontend/src/components/ExampleCarousel.tsx(신규), frontend/src/pages/Landing.tsx

## 한 일

무신사 메인 배너처럼 좌우 화살표로 넘겨 보는 카드 줄을 랜딩에 넣었다.
「이런 지출을 이렇게 봅니다」 절이다.

- 내용은 이미 있던 `DEV_EXPENSES` 6건을 그대로 쓴다
- 사진이 없으므로 **판정 색으로 칠한 카드**로 만들었다. 가능은 초록, 확인
  필요는 호박, 불가는 빨강이고 기호(`✓ ? ✕`)를 함께 붙인다. 레퍼런스가 사진
  위에 글씨를 얹은 자리를, 우리는 판정 색이 대신한다
- 동그란 화살표가 카드 좌우 끝에 걸친다. 처음이면 왼쪽, 끝이면 오른쪽이 숨는다
- 넓은 화면 3장 · 태블릿 2장 · 좁은 화면 1장. 좁은 화면에서는 다음 카드가
  살짝 보여 더 있다는 것을 알린다

## 왜 이렇게 했나

**transform 으로 밀지 않고 스크롤 스냅으로 만들었다.** 폭을 재서 미는 방식은
「한 줄에 몇 장 보이는지」를 자바스크립트가 알아야 하는데, 그 값이
브레이크포인트마다 달라 어긋나기 쉽다. 스냅은 브라우저가 폭을 맞추고,
손가락·트랙패드로도 그대로 넘어간다. 화살표는 `scrollBy` 만 부른다.

카드 내용을 실제 판정 사례(SK에너지 불가 등)로 할 수도 있었지만, 랜딩은
로그인 전 화면이라 특정 사용자의 거래를 보여줄 자리가 아니라고 봤다.
`DEV_EXPENSES` 는 업종 단위 예시라 그 자리에 맞는다.

자동 넘김은 넣지 않았다. 세금 판정 화면에서 저절로 움직이는 것은 방해가 된다.

## 보면서 고친 것

- **`prefers-reduced-motion` 이 무시되고 있었다.** CSS `scroll-smooth` 를
  걸어 두면 `scrollBy` 에 `behavior: 'auto'` 를 줘도 브라우저가 애니메이션을
  돌린다. CSS 클래스를 빼고 자바스크립트에서만 정하게 했다
- **좁은 화면에서 절 제목이 음절 단위로 꺾였다**(「이런 지출을 이렇게 봅니 /
  다」). `IrHeading` 에 `[word-break:keep-all]` 이 빠져 있었다. #151 에서
  빠뜨린 것이고, 그동안은 제목이 짧아 드러나지 않았다
