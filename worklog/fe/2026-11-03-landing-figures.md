## 한 일

### 1. 오른쪽 세로 띠에서 지어낸 금액·건수를 뺐다

로그인 전 방문자에게 「이번 달 인정 경비 21,483,000원 / 292건 중 168건 가능」을
보여 주고 있었다. 전부 `mock/marketing.ts` 의 `HERO_SUMMARY` 상수다. 실제 데이터처럼
보이지만 아무 근거가 없다. `HERO_SUMMARY` 를 지우고 그 자리를 이렇게 바꿨다.

| 전 | 후 |
| :--- | :--- |
| 이번 달 인정 경비 21,483,000원 | 검수를 마친 규칙 카드 53장 |
| 판정 분포 168 / 71 / 53 + 막대 | 판정 세 갈래 — 가능·확인 필요·불가 (건수 없이 설명만) |
| 지금 할 일 확인 필요 71건 | 되돌릴 수 없는 동작 없습니다 |

53 은 `rules/cards` 를 센 실제 장 수다(`ls rules/cards | wc -l` = 53).
`RULE_CARD_COUNT` 상수로 두고 아래 숫자 줄도 같은 값을 보게 했다 — 한 화면에서
「40+」와 「53장」이 같이 보이면 안 된다.

### 2. 숫자 줄에서 「허용하는 오탐 0건」을 뺐다

재 본 적이 없는 수다. 게다가 확신이 없으면 「확인 필요」로 내리는 제품이라
오탐 0 이라고 말할 수 있는 구조가 아니다. 4칸이 3칸이 되어 `md:grid-cols-4` 를
`md:grid-cols-3` 으로 바꿨다.

### 3. 히어로 2·3번 장면의 빈 가운데에 도식을 넣었다

첫 장면은 궤도가 가운데를 채우는데 2·3번은 제목과 항목 사이가 비어 있었다.
아래 항목과 같은 3열 격자(`gap-6 sm:grid-cols-3`)에 올리고
`preserveAspectRatio="xMinYMid"` 로 왼쪽 끝을 글자와 맞췄다.

- 판정 흐름: 올라온 거래 줄 / 답이 찬 문진 카드 / 초록·노랑·빨강 세 줄
- 하지 않는 일: 위로 올려보내는 화살표 / 확정 금액 / 밖으로 나가는 화살표

세 칸을 같은 그림으로 두었다가 고쳤다. 칸마다 다른 것을 말하는데 그림이 같으면
칸을 나눈 뜻이 없다.

빨간 금은 두 번 긋는다. 밑에 판 바탕색(`#152F56`)으로 굵게 한 번 깔아 틈을 낸다.
한 번만 그으면 금이 그림을 덮어 글리프가 안 읽힌다.

### 4. 인트로가 머무는 시간을 2000ms → 3500ms 로 늘렸다

`IntroOverlay` 의 모션은 마지막 조각이 1200ms 에 끝난다(`spread` 가 delay 500 + 0.7s).
`HOLD_MS` 가 2000 이면 완성된 화면이 **0.8초**만 보이고 사라진다. 이 화면은
`localStorage` 의 `preet.intro.seen` 으로 평생 한 번만 뜬다.

  처음엔 도식 자리의 여백이 모바일에도 걸려 3번째 항목이 잘렸다. `sm:py-8` 로 고쳤다.

## 남은 것 · 아는 문제

- **「적재된 조문·해석 버전 60건」은 확인하지 못했다.** 조문은 국가법령정보 API 에서
  받아 DB 에 쌓이고 저장소에는 없다. 참인지 거짓인지 모르는 채로 뒀다.
- `frontend/src/mock/trace.ts` 는 아무 데서도 쓰지 않는다. 이 작업 범위가 아니라 뒀다.
- `mock/` 폴더 이름 때문에 `marketing.ts`·`faq.ts` 가 API 목업으로 읽힌다.
  둘 다 로그인 전 소개 화면의 정적 글이고 `VITE_API` 와 무관하다.
