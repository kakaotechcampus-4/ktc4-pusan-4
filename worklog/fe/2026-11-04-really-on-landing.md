# 메인에서도 비서 Really 버튼이 보이게 한다

- 브랜치: feat/really-on-landing (develop 위)
- 커밋: 1개
- 주요파일: frontend/src/App.tsx, frontend/src/components/assistant/Assistant.tsx

## 한 일

`<Assistant />` 가 `SignedIn` 레이아웃 안에만 있었다. 그래서 **로그인한 채로 로고를
눌러 메인에 오면 버튼이 사라졌다** — 다른 화면에는 다 있다가 메인에서만 없어진다.

버튼을 라우트 바깥으로 올리고, 어디에 설지는 `Assistant` 가 정하게 했다.

| 상태 | 메인(`/`) | 그 밖의 공개 화면 | 로그인 뒤 화면 |
| :--- | :--- | :--- | :--- |
| 로그인함 | **버튼 + 대화** | **버튼 + 대화** | 버튼 + 대화 (전과 같음) |
| 로그인 전 | **버튼 → 로그인으로** | 없음 | — |

## 왜 이렇게 했나

로그인 전에는 대화를 열어 줄 수 없다. 실서버에 찔러 확인했다.

```
POST /api/v1/assistant/chat   (토큰 없이)
{"code":"UNAUTHORIZED","message":"로그인이 필요합니다."}   [401]
```

그래서 로그인 전 메인에는 **같은 모양의 버튼만 두고 누르면 `/login` 으로 보낸다**.
대화창을 열어 두면 보내는 족족 401 이다.

`/login`·`/signup`·`/faq` 같은 다른 공개 화면에는 두지 않았다. 로그인하러 온 화면에
「물어보기」 버튼이 있으면 할 일이 둘로 갈린다.

이어 가기(`restoring`) 중에는 아무것도 그리지 않는다. 안 그러면 새로고침할 때마다
로그인 버튼이 번쩍 떴다가 대화 버튼으로 바뀐다.

- 브라우저에서 두 상태를 다 눌러 봤다.
  - 로그인 전 `/` — 버튼 있음. `/login`·`/faq`·`/signup` — 없음.
  - 샘플 계정으로 로그인 → 메인에서 버튼을 누르니 대화 패널이 열렸다
    (`role="dialog"` `aria-label="비서 Really"` 확인).

## 남은 것 · 아는 문제

- 로그인 전 버튼은 **대화를 열지 않는다.** 비로그인 데모 대화를 보여 주려면 서버가
  `/assistant/chat` 을 토큰 없이 받아 줘야 한다. FE 만으로는 안 된다.
- 버튼 모양은 지금 것(검은 알약 + 봇 아이콘)을 그대로 썼다. 브랜드 Really 아이콘으로
  바꾸는 것은 별도 브랜치에서 한다.
