# 판정 중이면 확인 화면 대신 진행 화면으로, 어느 화면에서든 돌아갈 띠

- 브랜치: fix/run-active-return
- 커밋: 3b370994 (1개)
- 주요파일: Confirm.tsx, AppShell.tsx, api/contract.ts, api/mock/index.ts

## 한 일

- `api.runs.active()` (GET /judgment-runs/active, 204 는 null). 목업도 진행 중인 run 을 주고, 있으면 create 가 409 다.
- 판정 전 확인: 진행 중인 판정이 있으면 확인 화면을 그리지 않고 `/run/:id` 로 보낸다. 읽는 동안에는 확인을 그리지 않아 깜빡이지 않는다. 못 읽으면 확인 화면을 그대로 보인다.
- AppShell: 진행 중이면 머리말 아래에 「판정하고 있습니다」와 진행 보기 띠. 진행 화면과 판정 전 확인에서는 묻지 않는다.

## 왜 이렇게 했나

- 단계 표시의 판정, 결과, 요약, 거래 화면의 버튼이 모두 `/confirm` 으로 간다. 그 한 곳에서 보내면 판정 중에 다른 화면에 다녀와도 동의를 다시 받지 않고, 시작 버튼에도 닿지 않는다.
- 단계 표시는 md 미만에서 숨어 좁은 화면에서는 돌아갈 길이 없다. 그래서 띠를 따로 둔다. 숫자는 띄우지 않는다. 화면을 옮길 때만 읽어서 숫자가 멈춰 보인다.
